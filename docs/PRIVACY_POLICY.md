## 1. 基本方針

本ポリシーは、小惑星の検索・表示を支援する本ソフトウェアが取り扱う情報、外部送信および端末内の保存について説明します。確認した現行コードの範囲では、利用者アカウント、広告配信、開発者独自のアクセス解析サーバーへの定常的な情報送信は実装されていません。一方で、外部の天文データ・地図・標高サービスを使う機能には通信が必要です。

## 2. 利用する主な情報

| 情報 | 利用目的 |
| --- | --- |
| 小惑星名、番号、仮符号、SPK-ID等 | 対象天体の検索・特定 |
| 指定した日時、計算・取得の時間範囲 | 軌道要素や赤経・赤緯の取得と時刻表示 |
| 緯度・経度・標高、観測地点名 | 天体座標の計算、Stellarium上の観測地点設定 |
| Windowsが返す位置推定精度 | 現在地の精度の目安の表示 |
| 軌道要素、赤経・赤緯、追尾セッション | Stellariumへの登録・表示、マーカー・追尾 |

## 3. 現在地の取得と選択

1. 地図画面で利用者が「現在地を取得」を選択した場合、Windowsの位置情報機能から推定位置を取得します。端末の位置情報設定・アクセス許可の状態に依存します。
2. 現在地を取得せず、数値入力や地図選択で観測地点を指定できます。
3. 選択地点を確定すると、標高の推定のために地点の緯度・経度をOpenTopoDataへ送信します。現在地を元に選択した地点についても同様です。
4. 選択した地点を使って観測地点基準の赤経・赤緯を取得すると、緯度・経度・標高がJPL Horizonsへ送信されます。
5. OSおよび外部サービスが推定した位置や標高の正確性を保証するものではありません。

## 4. 外部通信先と送信される情報

| 接続先 | 主な送信情報 | 目的 |
| --- | --- | --- |
| `ssd-api.jpl.nasa.gov`（JPL SBDB） | 天体名・番号・識別子等 | 天体の照合・基本情報取得 |
| `ssd.jpl.nasa.gov`（JPL Horizons） | 天体識別子、日時・取得範囲・計算条件。観測地点を使う計算では緯度・経度・標高 | 軌道要素・赤経／赤緯の取得 |
| `tile.openstreetmap.org`（OpenStreetMap） | 表示対象の地図タイルを示すリクエスト | 地図画像の表示 |
| `api.opentopodata.org`（OpenTopoData） | 選択地点の緯度・経度（現行実装では小数第6位まで） | 標高推定値の取得 |

これらのサービスとの通信に伴い、通信元のIPアドレス、リクエストの日時等が相手方に認識・記録される可能性があります。地図タイルのリクエストから、表示地域が推測される可能性もあります。第三者サービス側の情報の管理・保存期間等については、各提供者のプライバシーポリシー等をご確認ください。

## 5. 端末内の処理・保存

1. 確認した構成では、Flutter GUIとPythonバックエンド間のAPI通信には同一端末上の`127.0.0.1:8000`を利用します。StellariumのRemote Controlとの通信には`localhost:8090`を利用します。
2. 赤経・赤緯の系列データや追尾セッションは、確認した現行実装ではPythonバックエンドのメモリ上に保持され、セッション消去またはプロセス終了によって破棄されます。
3. Stellariumへ軌道要素を登録する際、Stellariumユーザーデータ領域の`ssystem_minor.ini`が作成・更新されることがあります。
4. Stellariumの起動設定を準備する際に、`config.ini`が作成・更新されることがあります。既存ファイルのバックアップ（例：`config.ini.bak`、`ssystem_minor.ini.bak`）が作成される場合があります。
5. 変更した観測地点、時刻、登録天体等がStellarium側に残る場合があり、本ソフトウェアの終了やアンインストールですべて自動消去されるとは限りません。

## 6. 情報の管理・削除

1. 現在地へのアクセスはWindowsの位置情報設定で管理できます。現在地取得機能を利用しない選択もできます。
2. 赤経・赤緯の追尾セッションは、対応する操作またはバックエンドの終了により破棄されます。
3. Stellarium側の設定・登録データ・バックアップは、利用者が必要に応じてバックアップを取ったうえで管理・削除してください。
4. 外部サービスへ既に送られた情報を、本ソフトウェアから削除できるとは限りません。外部サービスの取扱いは各提供者の条件に従います。

## 7. セキュリティと注意点

確認したPythonバックエンドはループバックアドレスで待ち受けます。ただし、Stellarium Remote Controlのネットワークからの到達可能性は、Stellarium、Windowsファイアウォール等の設定に依存します。現時点で本ソフトウェアが外部からの通信を常に完全遮断するとは保証しません。

本ポリシーは、個人情報保護法その他の適用法令によって生じる義務を免除するものではありません。
