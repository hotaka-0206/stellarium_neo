# Astelock プライバシーポリシー

本ポリシーは、Astelock（以下「本ソフトウェア」）における利用者情報の取扱い、外部サービスへの通信および端末内のデータ保存について説明します。

提供者：Astelock開発者（GitHub：hotaka-0206）

## 1. 基本方針

本ソフトウェアは、小惑星の検索、軌道要素の取得、位置表示およびStellariumとの連携を目的とするアプリケーションです。

本ソフトウェアは、利用者アカウントの作成を必要とせず、広告配信や開発者独自のアクセス解析を目的とした情報収集を行わない構成を基本としています。

ただし、天体データ、地図および標高の取得に際して、外部サービスとの通信が発生します。

## 2. 取り扱う情報

本ソフトウェアは、機能提供のために以下の情報を取り扱います。

- 小惑星名、番号、仮符号、SPK-ID等の天体識別子
- 利用者が指定した日時および計算・取得の時間範囲
- 観測地点の緯度、経度、標高および地点名
- 現在地取得時にOSから提供される位置情報および推定精度
- 軌道要素、赤経・赤緯、表示対象および追尾情報

これらの情報は、天体の検索、位置計算、Stellariumへの登録・表示、地図表示および追尾等に利用します。

## 3. 現在地の取得

1. 利用者が現在地取得機能を選択した場合、Windowsの位置情報機能を使用して現在地を取得します。
2. 現在地の取得には、端末の設定やアクセス許可が必要となる場合があります。
3. 現在地取得機能の使用は任意であり、利用者は緯度・経度の入力や地図からの選択によって観測地点を指定できます。
4. 取得した位置または利用者が指定した地点は、標高取得や天体位置計算のために外部サービスへ送信される場合があります。
5. OSまたは外部サービスが提供する位置情報および標高の正確性は保証されません。

## 4. 外部通信先

本ソフトウェアは、主に以下の外部サービスと通信します。

### JPL Horizons

目的：小惑星の軌道要素、赤経・赤緯等の取得

送信情報：天体識別子、日時、計算条件、取得範囲および観測地点を使用する計算に必要な緯度・経度・標高等

https://ssd.jpl.nasa.gov/horizons/

### JPL Small-Body Database

目的：小惑星の識別子の照合および基本情報取得

送信情報：天体名、番号、仮符号、SPK-ID等

https://ssd-api.jpl.nasa.gov/doc/sbdb.html

### OpenStreetMap

目的：地図画像の取得および表示

送信情報：地図タイルの表示に必要なリクエスト情報

https://www.openstreetmap.org/

### OpenTopoData

目的：観測地点の標高推定

送信情報：標高を取得する地点の緯度・経度等

https://www.opentopodata.org/

これらの通信に伴い、通信元のIPアドレス、リクエスト日時、問い合わせ内容等が外部サービス側に認識または記録される場合があります。

外部サービスによる情報の保存、利用および削除等には、それぞれの提供者のポリシーが適用されます。

## 5. 端末内での処理・保存

1. 本ソフトウェアのFlutter GUIとPythonバックエンドは、同一端末上のローカルAPIを介して通信します。
2. Stellariumとの連携にはRemote Control機能を使用します。
3. 赤経・赤緯の系列データおよび追尾情報は、バックエンドのメモリ上で保持される場合があります。
4. 小惑星の登録に伴い、Stellariumの小天体設定ファイル（`ssystem_minor.ini`等）が作成・更新される場合があります。
5. 動作準備に伴い、Stellariumの設定ファイル（`config.ini`等）が変更される場合があります。また、既存ファイルのバックアップが作成される場合があります。
6. 本ソフトウェアの終了またはアンインストールによって、Stellariumに保存された設定、登録天体およびバックアップ等がすべて自動的に削除されるとは限りません。

## 6. ファイアウォールと通信の安全性

本ソフトウェアのインストール時には、Stellarium Remote ControlのTCP 8090番ポートへの受信通信を制限するために、Windowsファイアウォール規則を追加する場合があります。

この規則は、本ソフトウェアのアンインストール後も残る場合があります。

提供者は、端末の通信環境、他のソフトウェアおよび利用者の設定等によって生じるすべてのセキュリティ上の問題を防止できることを保証しません。

## 7. 情報の管理と削除

1. 位置情報へのアクセス許可は、Windowsの位置情報設定から管理できます。
2. メモリ上の追尾情報は、対応する操作またはバックエンドの終了によって破棄されます。
3. Stellariumに保存された設定、登録天体およびバックアップ等は、利用者が必要に応じて管理・削除してください。
4. 外部サービスへ送信済みの情報については、本ソフトウェアから削除できない場合があります。
5. 本ソフトウェアのアンインストールは、Windowsや外部サービスが保持する情報の削除を意味するものではありません。

詳細は、第三者ソフトウェア・サービスに関する通知をご確認ください。
