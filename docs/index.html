Astelockは、NASA JPL Horizonsのデータを活用し、 小惑星をStellarium上で表示・追尾するWindowsアプリケーションです。

地球近傍小惑星の表示精度に着目し、 軌道要素による表示と赤経・赤緯による表示を提供します。

About Astelock

天体の表示精度を探究する。

地球へ接近する小惑星では、軌道の違いが見かけの位置に 大きな差として表れることがあります。 Astelockは、高精度な天体暦を提供するJPL Horizonsと プラネタリウムソフトStellariumを連携させることで、 異なる表示方式の比較・検証を可能にすることを目指した、 卒業研究発のアプリケーションです。

Features

主な機能

JPLの天体データ取得からStellariumへの表示まで、 GUIから操作できます。

01 / ORBITAL ELEMENTS

軌道要素の取得・登録

指定日時の軌道要素をJPL Horizonsから取得し、 Stellariumへ小惑星を登録・表示します。

02 / RA & DEC

高精度位置表示・追尾

JPLの赤経・赤緯データをもとにマーカーを表示。 Stellariumの時刻に合わせて位置を更新します。

03 / OBSERVER

観測地点・日時の指定

地図での地点選択やWindowsの現在地取得に対応。 JSTとUTCを切り替えて日時を指定できます。

04 / SEARCH

さまざまな天体識別子に対応

小惑星番号、天体名、仮符号、SPK-ID、 日本語名などから対象天体を検索できます。

05 / STELLARIUM

Stellarium連携

Remote Control機能を使用して、 天体の表示や観測条件の設定を行います。 初期設定の一部も自動化しています。

06 / WINDOWS

GUIによる操作

FlutterによるWindows向け画面を提供。 PythonやFlutterの開発環境を用意せずに利用できます。

How It Works

Astelockの仕組み

天体情報の検索からStellariumでの可視化まで、 3つの要素を連携させています。

01. 対象天体を指定

小惑星名や番号などを入力し、 観測したい日時・地点を設定します。

02. JPLからデータを取得

NASA JPL Horizonsを利用して、 軌道要素または赤経・赤緯を取得します。

03. Stellariumで表示

取得した情報をStellariumへ反映し、 天球上の位置を視覚的に確認します。
