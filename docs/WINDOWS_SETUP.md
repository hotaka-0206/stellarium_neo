# Astelock Windows版 使用手順

このページでは、Astelockのインストールから初回起動、Stellariumへの天体表示までを説明します。

## 1. 動作環境

AstelockのWindows配布版は、64bit版Windows 10 / 11を対象としています。

必要なもの：

- Windows 10 / 11（64bit）
- Stellarium
- インターネット接続
- インストール時の管理者権限

PythonやFlutterのインストールは不要です。

## 2. Stellariumをインストールする

Stellariumがインストール済みの場合、この章は省略できます。

### 2-1. Stellariumをダウンロードする

Stellarium公式サイトにアクセスします。

https://stellarium.org/ja/

Windows x86_64向けのインストーラを選択してください。

提供されているバージョンやダウンロード画面は更新される場合があります。

### 2-2. Stellariumをインストールする

ダウンロードしたStellariumのインストーラを実行し、画面の案内に従ってインストールしてください。

インストール先を変更する必要がなければ、通常は初期設定のままで構いません。

Stellariumのインストールが完了したら、次の手順に進みます。

## 3. Astelockをダウンロードする

次のGitHub Releasesページを開きます。

https://github.com/hotaka-0206/stellarium_neo/releases/latest

「Assets」から、Windows用インストーラをダウンロードしてください。

バージョン0.2.0の場合、ファイル名は次のとおりです。

`Astelock-Setup-v0.2.0.exe`

バージョン番号は将来変更される場合があります。

**注意：** GitHubの「Source code (zip)」や「Source code (tar.gz)」は、一般利用者向けのインストーラではありません。

## 4. Windowsのダウンロード警告について

Astelockは個人開発のアプリケーションであり、実行ファイルのダウンロード実績やデジタル署名の状況によっては、Microsoft EdgeやWindows SmartScreenが警告を表示する場合があります。

例えば、次のような警告です。

- 「一般的にダウンロードされていません」
- 「WindowsによってPCが保護されました」

このような警告は、必ずしもマルウェアの検出を意味しません。ただし、安全性が保証されるわけでもありません。

必ず公式GitHubリポジトリのReleasesから取得したファイルであることを確認してください。

ファイルの入手元と安全性を確認し、自分で信頼できると判断した場合に限り、Edgeのダウンロードメニューから保持操作を行うか、SmartScreenの詳細情報から実行を選択してください。

提供元が不明なファイルや、セキュリティソフトによって脅威が検出されたファイルは実行しないでください。

## 5. Astelockをインストールする

1. ダウンロードした `Astelock-Setup-v0.2.0.exe` を実行します。
2. Windowsのユーザーアカウント制御が表示された場合は、内容を確認します。
3. セットアップ画面に従って進みます。
4. 利用規約とプライバシーポリシーを確認します。
5. 必要に応じてデスクトップショートカットの作成を選択します。
6. インストールを実行して完了します。

Astelockのインストーラは、WindowsファイアウォールにStellarium Remote Controlへの外部受信通信を制限するための規則を設定します。

インストール中に、他のアプリケーションがファイルを使用しているという警告が出る場合があります。

その場合、無理に処理を続行せず、関係するアプリケーションを終了するか、Windowsを再起動してから再実行してください。

## 6. Astelockを起動する

インストール完了後、スタートメニューから「Astelock」を探して起動します。

デスクトップショートカットを作成した場合は、そのショートカットから起動することもできます。

GUIを起動すると、必要なPythonバックエンドも自動的に起動します。

Pythonのコマンド入力やサーバーの手動起動は不要です。

## 7. Stellariumの初期設定

Astelockでは、Stellariumの初期設定の一部を自動化しています。

AstelockからStellariumを起動する際に、必要に応じて次の設定を適用します。

- Remote Controlプラグインの有効化
- Remote Controlの自動起動
- 通信ポートを8090に設定
- フルスクリーン表示の無効化

通常、Remote Controlの設定を手動で変更する必要はありません。

### 注意事項

すでにStellariumが起動している場合は、一度終了してからAstelockを使用してください。

また、Stellariumの設定ファイルが変更される場合があります。

## 8. 動作確認

例として、小惑星Apophisを検索します。

1. Astelockを起動します。
2. 天体の検索欄に `99942` または `Apophis` と入力します。
3. 天体を検索し、情報が取得できることを確認します。
4. 表示方式と日時などを指定します。
5. Stellariumへの表示操作を実行します。
6. Stellarium上に対象の小惑星またはマーカーが表示されることを確認します。

正常に表示されれば、基本的な動作確認は完了です。

## 9. 観測地点と現在地の取得

RA / Dec方式では、観測地点を指定できます。

- 緯度・経度・標高を入力する
- 地図上で地点を選択する
- Windowsの位置情報機能で現在地を取得する

現在地を取得する場合は、Windowsの位置情報サービスが有効である必要があります。

地点を確定する際、標高取得のために外部サービスへ選択地点の座標が送信される場合があります。

地図や標高などの外部サービスを使用する機能には、インターネット接続が必要です。

## 10. トラブルシューティング

### Stellariumに接続できない

以下を確認してください。

1. Stellariumを一度終了する。
2. AstelockからStellariumを起動する。
3. StellariumのRemote Controlプラグインが有効か確認する。
4. Remote Controlのポート番号が `8090` か確認する。
5. 必要に応じてStellariumを再起動する。

Remote Controlの設定は、Stellariumの設定画面から確認できます。

### 天体情報を取得できない

JPL Horizons等に接続するため、インターネット接続を確認してください。

外部サービスの障害や利用制限によって、データを取得できない場合もあります。

### 現在地を取得できない

Windowsの位置情報サービスと、アプリによる位置情報アクセスの設定を確認してください。

現在地を取得できない場合でも、緯度・経度・標高の手入力や地図からの選択が可能です。

### Stellariumが全画面表示になっている

Stellarium上で `F11` を押すと、全画面表示を切り替えられます。

キーボードによっては `Fn + F11` が必要です。

### インストール時にアプリケーションを終了するよう求められる

インストーラが更新対象のファイルを使用中と判断している場合があります。

Astelockや関連アプリケーションを終了し、必要ならWindowsを再起動してからインストーラを再実行してください。

### セキュリティソフトが警告を出す

警告の詳細、対象ファイル、検出名を確認してください。

不審な検出がある場合は、安易にセキュリティ機能を無効化しないでください。

## 11. 更新・アンインストール

更新版が公開された場合は、公式GitHub Releasesから新しいインストーラを取得してください。

Astelockの終了を確認してから実行してください。

アンインストールする場合は、Windowsの「設定」→「アプリ」→「インストールされているアプリ」からAstelockを選択します。

**注意：** Astelockをアンインストールしても、Stellariumの設定、登録済みの小惑星、バックアップファイル、Windowsファイアウォールの規則などが自動的に元へ戻るとは限りません。

必要に応じて設定を確認してください。
